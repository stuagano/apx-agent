## Deliberately NOT auto-fixed — needs a decision (tracked as issues)

### A. Identifier interpolation (table/column names) in SQL
`sql_literal()` escapes string **literals**, not identifiers, and you cannot
bind a table name as a parameter — so the "just use `sql_literal`" advice does
**not** apply here. These need a name validator/allowlist. Blast radius is
bounded by OBO identity (caller's own grants).
- `data-inspector/tools.py` — `delta_bisect` (L112), `delta_bisect_column`
  (L195–201), `version_diff` (L267–273), `audit_lookup` (L296–306),
  `get_table_info` (L66): `table`/`condition`/`column` interpolated verbatim.
- `data-triage-agent/tools.py` — `get_table_lineage` (L87), `find_jobs_for_table`
  (L109), `get_table_info` (L63): `table_full_name` interpolated.
- `contract-parsing-agent/tools/extract_new_contract.py` — `volume_path` passed
  to `Path()`/INSERT with no `/Volumes/` prefix check.

### B. Composition primitive choices (behavior change)
- ~~`customer_triage` — `HandoffAgent` → `RouterAgent`~~ — done (#600, local
  example only; fleet stays A2A `sub_agents=[url]`).
- `entity-resolution-agent` — supervisor↔evaluator retry is a generator-critic
  loop; `LoopAgent` expresses the exit condition structurally vs. relying on
  instruction-following. **Deferred:** apx `LoopAgent` wraps one agent +
  `finish_loop()`, not two peers — Handoff remains the honest fit until a
  Sequential-inside-Loop redesign.

### C. Tool-shape judgment calls — resolved (#601)
- `customer_triage[_fleet]` — removed `format_address` (pure string formatting;
  LLM formats directly). Billing tools are `get_recent_orders` only.
- `contract-parsing-agent` — merged `find_contracts_expiring` into
  `query_portfolio(expires_within_days=)` (also excludes already-expired rows).
- `explain-my-bill-agent` — kept `compare_months` as one domain job; tightened
  docstring + instructions so the LLM does not reassemble MoM from other tools.
- `shortage-intelligence-agent` — `validate_against_market_news` now returns
  Vector Search evidence only; the market_agent synthesizes CONFIRMED /
  UNCONFIRMED (no nested LLM). `eligibility-agent` PDF vision parse keeps a
  bounded nested multimodal call (image payload cannot round-trip as tool text)
  and declares the serving endpoint + documents table via `attach_resources`.
- Added `attach_resources` on UC-touching tools in `contract-parsing-agent`,
  `shortage-intelligence-agent`, `explain-my-bill-agent`, and
  `eligibility-agent` `parse_documents`.

### D. Safety posture on demo examples — resolved (#602)
- `customer_triage`, `customer_triage_fleet`, `memory_demo` — wired
  `_use_dep_principal=True` so Apps requests resolve memory from
  `Dependencies.Principal`; kept `default_principal_id` as local/smoke
  fallback and documented the shared-fallback as a **DEPLOY BLOCKER**.
- `slack-agent` — OAuth nonce map now has a 10-minute TTL + purge; token store
  README/code call out **DEPLOY BLOCKER** (still in-memory by design for the
  manual OBO reference).
- `apx-builder` — validates `app_name` / `use_case` / table / Genie ids before
  codegen; `scaffold_project` + `deploy_agent` go through a `PolicyGate` ASK.

### E. Ergonomic / consistency (Minor) — partially resolved (#602)
- `max_iterations` unset on most agents — left optional; apply per-agent only
  where a real latency/cost ceiling matters (no blanket).
- `databricks-apx-agent` scaffold — replaced stub
  `description=<placeholder>` with a filled example, and switched the Genie
  path to `genie_tool()` (declares resources) instead of a hand-rolled poll.
## Explicitly reviewed and found NOT a defect
- **MCP-server bare `raise ValueError` on invalid action** (`jobs.py`,
  `unity_catalog.py`, ~10 sites). The auditor called this inconsistent, but
  `jobs.py` has zero `{"error":...}` returns — bare-raise IS the file's
  convention, and `middleware.py` catches all exceptions into a structured
  `isError=True` envelope. Changing these would fight the codebase's own error
  architecture. Left as-is.

## Exemplary (leave alone)
`zero-ops-diagnostics` (RouterAgent + clamped inputs + escaped filters),

## Pre-existing note (not introduced, worth tracking)
`databricks_tools_core.sql.sql_literal` only doubles single quotes; it does not
escape backslashes (unlike `apx_agent`'s `sql_escape`). The fixes in category 1
use the escaping the example already had available; a hardening pass could move
these to `sql_escape` or bind parameters throughout.
